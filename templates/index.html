ABOUT OUR PROJECT

Technology that
understands your voice.

Voxify is a Python-based Speech-to-Text web application. It provides an easy-to-use interface that allows users to convert spoken words into written text.

The application uses Flask for its web server and browser speech recognition for voice input. Users can view, copy, and download the converted text.
